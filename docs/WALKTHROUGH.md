# 4#304 寝室专属搞笑日常小程序 (Dorm Daily Fun) 交付与使用说明书

## 1. 项目简介与架构成果
本项目是专为 **`4#304`** 寝室打造的高私密、强互动、0运营费用的专属搞笑日常小程序。跳出传统生产力文档（Notion/语雀）的冰冷，建立了专属的寝室梗文化阵地。

* **技术栈**：Vue 3.4 + Uni-app (Vite 5) + Pinia + SCSS + Vitest
* **远程仓库**：[https://github.com/chenchen320/dorm-daily-fun](https://github.com/chenchen320/dorm-daily-fun)
* **费用说明**：**100% 永久免费架构**。采用数据适配器模式（`IStorageAdapter`），无需按月缴纳微信官方云开发的 19.9 元/月费用。
* **质量指标**：**25 个自动化单元测试 100% 通过**，微信小程序端已完成正式制品构建。

## 2. 核心功能与玩法矩阵

### 🚪 1. 寝室专属门禁与身份认领系统
* **双重密码防蹭**：必须输入房号 `4#304` + 进房密钥（初始默认: `304888`）。
* **6 大专属角色池**：`寝室长`、`小肥肥`、`晴晴姨`、`皇上`、`哈基`、`王晨`。
* **互斥与微信绑定**：角色一经认领即与设备/微信 OpenID 绑定，防冒领。
* **物理满员闭门**：达到设定上限后通道自动锁死，杜绝外寝人员蹭寝。

### 📜 2. 搞笑日常流与配图发布 (Feed)
* **快速发布**：支持输入事件文字、多选 `@受害主角`、1~5 星沙雕指数打分。
* **配图防爆**：支持 1~9 张现场照片（单张 <= 5MB 自动校验），自适应九宫格并支持原生全屏放大查看。
* **🕵️ 匿名树洞模式 (`[来吐槽吧]`)**：
  * 选择此标签发布时，作者姓名与头像强制脱敏为“**神秘室友**”，并在卡片左侧渲染暗夜紫色边框。
  * 该帖子下所有室友的评论也全部匿名，互猜内战，零心理压力真实吐槽！

### 🤣 3. 专属表态 (Reactions) 与神评吐槽
* **4 大快捷表态**：🤣 `笑喷`、🤯 `逆天`、📁 `留档存证`、🚪 `开除寝籍`。
* **全量 Emoji 扩展**：点击 `➕` 号展开支持任意标准 Emoji（👋, 🤡, 💩, 💀, 🐂, 🍺 等）。
* **防重复防刷机制**：已表态的表情再次点击自动取消（乐观更新响应 < 10ms）。
* **吐槽抽屉**：底部上滑查看所有室友评论，支持一键切换“匿名吐槽”。

### 💬 4. 寝室黑话词典与今日金句墙
* **自动收录管道**：发布时标记 `[黑话梗合集]` 时，系统自动收录进词典。
* **每日镇寝神句**：首页置顶高亮展示 TOP 1 金句（如：“*‘这道题选C，不选C我倒立洗头’ —— 王晨*”）。
* **黑话排行榜**：支持室友给经典词条点赞膜拜。

### 🎡 5. 寝室命运之轮 (决策大转盘)
* **三大预设日常决策场景**：
  1. 🛠️ **谁来报修**
  2. 💡 **谁下床关灯**
  3. 📦 **谁帮忙拿快递**
* 扇区自动填充 6 位室友名字，高帧率动态旋转并弹窗播报“今日天选倒霉蛋”。

### 🗞️ 6. 年度沙雕黑料小报 (Recap)
* 自动统计“**年度受害王**”（被 @当事人 最多的室友，如王晨）。
* 自动提取“**最高沙雕核爆事件 TOP 3**”。
* 复古长图报纸风格排版，支持截屏直接发到微信群互相嘲笑。

### 👑 7. 寝室长管理后台
* **动态扩容/缩容**：自由调节寝室人数上限（必须 >= 当前在席人数）。
* **移出室友**：寝室长可执行移出操作，对应角色名额立即释放回可选角色池。
* **更新置顶公告**与**重置进房独立密钥**。

## 3. 运行与预览指南

### 方式 A：微信开发者工具真机预览 (推荐)
1. 下载并安装官方 **微信开发者工具**。
2. 打开微信开发者工具，点击 **导入项目**。
3. 项目目录选择：`D:\dorm-daily-fun\dist\build\mp-weixin`。
4. AppID：输入你的真实 AppID（或者选择“测试号”模式）。
5. 导入后即可直接在模拟器和真机上扫码把玩！

### 方式 B：本地浏览器极速预览 (Vue3 模式)
```bash
cd D:\dorm-daily-fun
pnpm dev:h5
```
浏览器打开控制台输出的地址（如 `http://localhost:5173`）即可秒级调试全部页面与组件。

### 方式 C：运行自动化测试
```bash
cd D:\dorm-daily-fun
pnpm test
```
执行全部 6 个测试套件，验证 25 项业务断言。
